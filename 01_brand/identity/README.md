# Visual Identity

Diretrizes iniciais para a construção da identidade visual da NEXA Studio.

## Direção

A NEXA deve transmitir:

- contemporaneidade;
- tecnologia;
- sofisticação;
- criatividade;
- clareza;
- profissionalismo.

## Princípio

A identidade deve funcionar como um sistema visual consistente, aplicável a apresentações, propostas, portfólio, redes sociais, websites, projetos digitais e materiais institucionais.

## Status

**Estratégia aprovada — identidade visual em desenvolvimento.**

Logo, paleta, tipografia, grid e demais elementos serão definidos em etapa própria após a validação da estratégia.
