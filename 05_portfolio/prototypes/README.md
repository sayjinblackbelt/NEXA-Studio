# NEXA Studio — Prototype Portfolio

> **PROTÓTIPOS CONCEITUAIS — NÃO SÃO TRABALHOS DE CLIENTES**

Esta área reúne projetos fictícios desenvolvidos para demonstrar a capacidade criativa do studio enquanto o portfólio comercial real ainda está sendo formado.

## Projetos

- ORBITA — identidade / sistema visual
- PULSE — design digital / interface
- MOVE — campanha / comunicação
- FORMA — editorial / design gráfico

Cada projeto deve registrar contexto fictício, desafio, conceito, processo, aplicações e resultado conceitual.

Quando trabalhos reais forem aprovados para publicação, eles devem entrar em `05_portfolio/` seguindo o padrão oficial de cases.
