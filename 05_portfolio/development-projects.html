02 / ABOUT DEPLOYMENT

Portfólio estático, aplicações independentes

Esta página é publicada como conteúdo estático no GitHub Pages. As aplicações interativas foram construídas com Streamlit e Python e, neste momento, foram validadas localmente. Para executar cada aplicativo na internet é necessário um serviço de hospedagem compatível com Python, configuração de dependências e revisão de segurança, privacidade e custos.

Os dados e arquivos gerados durante os testes são de demonstração. Nenhum indicador de desempenho comercial é reivindicado nesta página.
