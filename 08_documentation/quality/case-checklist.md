# Case Checklist

- [ ] Contexto documentado
- [ ] Problema/desafio documentado
- [ ] Objetivos registrados
- [ ] Estratégia explicada
- [ ] Processo documentado
- [ ] Solução apresentada
- [ ] Entregáveis identificados
- [ ] Resultado ou impacto registrado quando disponível
- [ ] Papel da NEXA identificado
- [ ] Ferramentas e créditos registrados
- [ ] Autorização de publicação verificada
- [ ] Assets de apresentação preparados
- [ ] Case revisado editorialmente
