# Design Checklist

## Estratégico
- [ ] A solução atende ao problema definido
- [ ] A hierarquia comunica a mensagem principal

## Visual
- [ ] Tipografia revisada
- [ ] Alinhamentos e espaçamentos revisados
- [ ] Cores conferidas
- [ ] Imagens e elementos gráficos adequados
- [ ] Identidade visual aplicada corretamente

## Conteúdo
- [ ] Textos revisados
- [ ] Informações e dados conferidos
- [ ] Logos e créditos corretos

## Técnico
- [ ] Dimensões corretas
- [ ] Resolução adequada
- [ ] Arquivo editável preservado
- [ ] Exportação adequada ao uso
