# Briefing Checklist

- [ ] Cliente e contexto identificados
- [ ] Problema/desafio definido
- [ ] Objetivo principal definido
- [ ] Público identificado
- [ ] Entregáveis e formatos identificados
- [ ] Prazo e marcos registrados
- [ ] Restrições identificadas
- [ ] Referências reunidas
- [ ] Critérios de sucesso definidos
- [ ] Dúvidas críticas resolvidas
