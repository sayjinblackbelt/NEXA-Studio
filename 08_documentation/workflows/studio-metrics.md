# Indicadores do Studio

## Objetivo

Usar poucos indicadores para enxergar capacidade, fluxo, qualidade e evolução da NEXA Studio.

## Indicadores iniciais

### Operação
- Projetos ativos
- Projetos por etapa
- Projetos atrasados
- Projetos bloqueados
- Pendências abertas

### Qualidade
- Revisões por projeto
- Projetos aprovados na primeira apresentação
- Retrabalho recorrente

### Fluxo
- Tempo médio de projeto
- Projetos concluídos
- Projetos em andamento

### Relacionamento
- Clientes ativos
- Clientes recorrentes
- Oportunidades em aberto

## Princípios

Indicadores servem para decisão, não para criar burocracia. Medir somente aquilo que puder orientar uma ação.
