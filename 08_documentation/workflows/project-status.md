# Project Status

## Status do fluxo

`BACKLOG` → `BRIEFING` → `STRATEGY` → `CONCEPT` → `PRODUCTION` → `REVIEW` → `APPROVAL` → `DELIVERY` → `CASE` → `COMPLETED` → `ARCHIVED`

## Saúde

`ON TRACK` — dentro do esperado.

`ATTENTION` — existe risco ou pendência relevante.

`BLOCKED` — existe impedimento que impede o avanço.

`ARCHIVED` — projeto encerrado e retirado da operação ativa.
