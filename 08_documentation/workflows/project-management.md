# Project Management Workflow

## Fluxo

```text
Planejamento
→ Tarefas + Marcos
→ Acompanhamento
→ Riscos / Bloqueios
→ Decisões
→ Entrega
→ Indicadores
```

## Princípio

Registrar somente informações que ajudem a tomar decisões, acompanhar progresso ou preservar conhecimento.

## Saúde do projeto

- `ON TRACK` — dentro do esperado.
- `ATTENTION` — risco ou pendência relevante.
- `BLOCKED` — impedimento que impede o avanço.
- `ARCHIVED` — projeto encerrado/arquivado.
