# Approval Workflow

1. Preparar a versão para apresentação.
2. Realizar QA interno.
3. Registrar a versão apresentada.
4. Consolidar o feedback recebido.
5. Registrar o estado da aprovação.

## Estados

`PENDING` — aguardando retorno.

`APPROVED` — versão aprovada.

`CHANGES_REQUESTED` — alterações solicitadas.

## Registro

```text
Versão:
Data:
Aprovado por:
Canal:
Observações:
Status:
```
