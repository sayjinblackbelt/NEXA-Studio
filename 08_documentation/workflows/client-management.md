# Gestão de Clientes

## Objetivo

Organizar o relacionamento com clientes desde o primeiro contato até o pós-projeto, mantendo histórico suficiente para continuidade e recorrência.

## Fluxo

`LEAD → CONTACTED → QUALIFIED → PROPOSAL → ACTIVE → COMPLETED → FOLLOW-UP → RECURRENT / INACTIVE`

## Princípios

- Registrar apenas informações necessárias à operação.
- Não armazenar credenciais, documentos sensíveis ou dados financeiros confidenciais.
- Cada projeto deve apontar para seu cliente.
- O histórico deve preservar decisões e aprendizados úteis para trabalhos futuros.
- O pós-projeto deve gerar feedback, resultado e possíveis oportunidades.

## Ciclo do relacionamento

1. **Contato** — registrar a oportunidade.
2. **Qualificação** — verificar necessidade, aderência e capacidade de atendimento.
3. **Proposta** — apresentar a solução e o escopo correspondente.
4. **Ativo** — acompanhar projetos em execução.
5. **Conclusão** — registrar entrega e resultado.
6. **Follow-up** — coletar feedback e identificar necessidades futuras.
7. **Recorrência** — manter o relacionamento quando houver novos projetos.

## Histórico mínimo

- projetos realizados;
- principais decisões;
- aprovações relevantes;
- entregas;
- feedbacks;
- aprendizados;
- oportunidades futuras.
