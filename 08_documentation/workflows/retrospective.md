# Project Retrospective

A retrospectiva acontece após a entrega para transformar experiência em melhoria operacional.

## Perguntas

1. O briefing foi suficiente?
2. O diagnóstico estava correto?
3. Onde houve retrabalho?
4. O que atrasou o projeto?
5. O que funcionou bem?
6. O processo de aprovação foi eficiente?
7. O escopo foi respeitado?
8. O que deve mudar no próximo projeto?
9. O projeto merece virar case?
10. Existe algum aprendizado que deve virar template, checklist ou guideline?

## Registro

```text
Projeto:
Data:
Pontos positivos:
Problemas:
Retrabalho:
Aprendizados:
Ações de melhoria:
Case recomendado: SIM / NÃO
```

> Todo projeto deve gerar não apenas uma entrega, mas também aprendizado para o próximo projeto.
