# Revision Workflow

```text
Versão de trabalho
→ Revisão interna
→ Apresentação
→ Feedback consolidado
→ Nova versão
→ QA
→ Aprovação
```

## Regras

- Separar revisão interna de revisão do cliente.
- Consolidar feedback antes de iniciar alterações.
- Identificar cada nova versão.
- Verificar se alterações solicitadas estão dentro do escopo.
- Registrar pendências e decisões relevantes.
