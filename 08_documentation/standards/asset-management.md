# Gestão de Assets

## Categorias

- brand
- typography
- icons
- mockups
- templates
- photography
- illustrations
- references

## Critérios

Todo asset reutilizável deve ter origem/licença conhecida, finalidade clara e nome consistente.

## Status

`DRAFT → APPROVED → ACTIVE → ARCHIVED`

## Regra

Assets específicos de um cliente devem permanecer no contexto do projeto/cliente. A biblioteca compartilhada deve conter apenas recursos autorizados para reutilização.
