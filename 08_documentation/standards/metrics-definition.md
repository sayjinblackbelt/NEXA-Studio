# Definição de Indicadores

| Indicador | Definição | Frequência |
|---|---|---|
| Projetos ativos | Projetos em execução | Mensal |
| Atrasados | Projetos além do prazo previsto | Semanal |
| Bloqueados | Projetos com impedimento relevante | Semanal |
| Pendências abertas | Itens que aguardam ação | Semanal |
| Revisões por projeto | Ciclos de revisão registrados | Por projeto |
| Tempo médio | Dias entre início e conclusão | Mensal |
| Clientes recorrentes | Clientes com novos projetos após conclusão | Mensal |

## Regra

Sempre registrar período e fonte. Não comparar indicadores sem considerar volume e contexto.
