# Task Management Standard

## Prioridades

- `P1` — crítica
- `P2` — importante
- `P3` — normal

## Registro

```text
- [ ] P2 — Tarefa — responsável — prazo
```

## Regras

- Uma tarefa deve representar uma ação concreta.
- Tarefas concluídas devem permanecer registradas com `[x]`.
- Dependências ou bloqueios relevantes devem ser registrados na seção de riscos/bloqueios.
- Não transformar o acompanhamento em uma lista excessivamente detalhada.
