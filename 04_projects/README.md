# Projetos

Área central de produção e documentação dos projetos da NEXA Studio.

## Estrutura padrão

```text
04_projects/
└── NEXA_Projeto_Nome/
    ├── README.md
    ├── 01_discovery/
    ├── 02_strategy/
    ├── 03_concept/
    ├── 04_design/
    ├── 05_revision/
    ├── 06_approval/
    ├── 07_delivery/
    └── 08_case/
```

## Status

`BACKLOG` → `BRIEFING` → `STRATEGY` → `CONCEPT` → `PRODUCTION` → `REVIEW` → `APPROVAL` → `DELIVERY` → `CASE` → `COMPLETED` → `ARCHIVED`

## README do projeto

O README mestre deve registrar projeto, cliente, categoria, responsável, datas, status, prioridade, objetivo, desafio, escopo, entregáveis, cronograma, aprovações, pendências, arquivos, resultado e relação com o portfólio.

## Versionamento

Usar `v01`, `v02`, `v03` etc. para versões de trabalho. Após aprovação, distinguir claramente a versão aprovada e a versão efetivamente entregue.

Evitar nomes ambíguos como `final_final2`.
