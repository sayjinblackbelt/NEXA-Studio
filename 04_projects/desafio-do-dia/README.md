# Desafio do Dia — UI / Visual System

Projeto digital educacional gamificado desenvolvido por Filipe Gimenes de Morais.

## Escopo anexado ao NEXA Studio

Esta pasta preserva a camada visual e de interface do projeto `sayjinblackbelt/desafio-do-dia`, incluindo:

- layout HTML;
- sistema principal de CSS;
- estilos de desafio diário;
- estilos de metas semanais;
- estilos de conquistas/badges;
- referências de responsividade;
- estados de interface e componentes visuais.

## Direção visual

**Conceito:** aprendizagem rápida + gamificação discreta + interface educacional contemporânea.

**Paleta principal:**

- Indigo `#4f46e5` — ação e destaque;
- Indigo escuro `#3730a3` — estado hover;
- Fundo `#f4f7fb` — superfície geral;
- Branco `#ffffff` — cards;
- Texto `#172033` — hierarquia principal;
- Cinza `#657084` — informação secundária;
- Verde `#16834d` — feedback positivo.

## Componentes visuais

1. Header / identidade da aplicação
2. Banner do desafio diário
3. Indicadores de XP, desafios concluídos e sequência
4. Barra de progressão de nível
5. Filtros por categoria e nível
6. Card principal do desafio
7. Botões primário e secundário
8. Histórico de desafios
9. Metas semanais
10. Badges / conquistas
11. Footer informacional

## Responsividade

O layout foi concebido mobile-first de forma progressiva, com quebra de grid para telas menores e botões em largura integral no mobile.

## Fonte

A pilha tipográfica utiliza `Inter` com fallback para `system-ui`, evitando dependências externas obrigatórias.
