# Portfólio de desenvolvimento Python

Os cinco projetos Python foram migrados para o repositório dedicado:

**[sayjinblackbelt/Python-Projects](https://github.com/sayjinblackbelt/Python-Projects)**

Nesse repositório estão o código-fonte, os testes automatizados, as dependências e a documentação de cada aplicação.

## Projetos

- FinTrack Lite — controle financeiro pessoal.
- TaskFlow Python — gerenciamento de tarefas com SQLite.
- QuizLab — quiz de múltipla escolha.
- DataClean Mini — inspeção e limpeza de arquivos CSV.
- FileOrganizer — organização de arquivos por extensão.

Os testes locais foram executados no MacBook Neo e passaram: 25 testes no total (4 + 5 + 5 + 5 + 6). Esse resultado representa uma validação automatizada inicial, não uma auditoria completa nem garantia de prontidão para produção.

Para abrir o portfólio visual, consulte a [página de desenvolvimento da NEXA Studio](../05_portfolio/development-projects.html).
