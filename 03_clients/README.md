# Clientes

Área de organização dos clientes da NEXA Studio.

## Estrutura

```text
03_clients/
└── nome-do-cliente/
    ├── README.md
    ├── 01_briefing/
    ├── 02_projetos/
    ├── 03_aprovacoes/
    ├── 04_entregas/
    └── 05_historico/
```

O README de cada cliente funciona como ficha mestre e deve conter apenas informações adequadas ao armazenamento neste repositório. Dados pessoais, credenciais, documentos sensíveis ou informações financeiras confidenciais não devem ser armazenados aqui.
